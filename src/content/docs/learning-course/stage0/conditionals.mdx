In the [previous lesson](/learning-course/stage0/operators/), we used comparison and logical operators to produce `true` or `false` values.
In this lesson, we're going to use those values to make decisions with **conditionals**, which run a block of code only when a condition is true.

## Why Conditionals?

In everyday life, we make decisions all the time, like "If I'm hungry, I get a snack."
Robots make decisions too, like "If the robot is far from the wall, drive forward," or "If the match timer reaches 0, stop driving."
So far, every line of code we've written runs every time.
Conditionals let us choose which code runs based on values like a sensor reading or the time left in the match.

We'll cover three kinds of conditionals: `if`, `else`, and `else if`.

<Aside type="note">
    Java also has a `switch` statement, which isn't covered here because it's
    rarely used in FRC. If you want to learn more about it, see
    [w3schools](https://www.w3schools.com/java/java_switch.asp).
</Aside>

## The `if` Statement

An **`if` statement** runs a block of code only if its condition is true:

```java #ifSyntax

```

An `if` statement has three parts:

- the `if` keyword
- a condition in parentheses, which is either true or false, like `6 > 2`
- a **code block**, which is the code between the curly braces `{` and `}`

If the condition is true, the code block runs.
If it's false, the code block is skipped, and the program moves on to the code after it.

The code block runs, printing `Driving at full speed` and setting the drivetrain to full speed.
If `distance` were 5 instead, the condition would be false, and nothing would be printed.

    Every conditional in this lesson follows the same pattern: a keyword,

</Aside>

## Adding an `else`

An `if` statement on its own does nothing when its condition is false.

## Adding `else if`

`if` and `else` choose between two options, but sometimes we need more.
An **`else if`** adds another condition, which is only checked if every condition before it was false:

```java #elseIfSyntax

```

Java checks the conditions from top to bottom, and runs the code block for the _first_ one that's true.
Once one code block runs, the rest are skipped, even if their conditions are also true.
If none of the conditions are true, none of the code blocks run.

Let's use `else if` to slow the robot down as it gets closer to the wall:

```java #elseIfExample

```

`distance` is 30, so the first condition, `distance > 50`, is false, and Java moves on to the `else if`.
`distance > 10` is true, so the robot drives at half speed.

The order of the conditions matters here.
A `distance` of 60 is greater than both 50 _and_ 10, but only the first matching block runs, so the robot drives at full speed.
If we had checked `distance > 10` first, the robot would drive at half speed even when it's far from the wall.
