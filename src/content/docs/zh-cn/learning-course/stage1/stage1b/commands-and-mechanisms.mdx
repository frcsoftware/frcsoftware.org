### 将命令与机构结合

下面是一个定义在机构类内部的命令示例：

```java #fullThrottleIntake

```

用 `run()` 创建的命令会自动占用定义它的那个机构。
这里，全速运行命令占用的是 `Intake`。

另外，注意 `fullThrottle` 方法会创建并返回一个命令。
所有机构专用的命令都应该这样定义，原因有两个：

1. 命令可以像方法一样定义参数。
2. `Robot` 类可以方便地使用这些命令。

```java #runAtThrottleCommand

```

不过，使用这种方式时需要小心。
看看下面这段代码：

{/* rli:ignore */}

```java
public Command printHiThenFullThrottle() {
  return run(coroutine -> {
      System.out.println("Hi!");
      runAtThrottle(1.0); // Error: Commands must be used! Did you mean to fork it or bind it to a trigger?
    })
    .named("Set to Full Throttle");
}
```

像这样调用 `fullThrottle()` 方法，并不会让电机转动，而是会创建一个必须单独运行的 `Command` 对象。
Java 编译器会发现这个问题，并报出编译时错误。
