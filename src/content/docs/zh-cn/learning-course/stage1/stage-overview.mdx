恭喜！
无论你之前已经会 Java、为 FRC 机器人编写过程序，还是完全的新手，到现在你都应该已经较好地掌握了 Java 语言。
在阶段 1 中，我们将进入最令人兴奋的部分：真正为机器人编写代码！
一开始可能会觉得有些困难，但最好的方法是专注于理解代码中每个组成部分是如何工作的，而不是试图一次性全部掌握。

本阶段介绍如何为 2026 年 FIRST Robotics Competition 的赛题 REBUILT，编写一台完整可用的 Kitbot 的程序。
你将从阶段 1A 开始，它介绍一种为 Kitbot 编程的简单方式。
接着进入阶段 1B，它使用一种稍复杂一些的编程范式，称为 commands（命令）。
此外，你还会在 simulation（仿真）中调试机器人，检查代码是否正常工作！
最后是阶段 1C，它详细介绍如何使用 telemetry（遥测）记录和读取机器人数据，以及如何使用 PID 进行基础的机器人控制。
完成之后，可以在仿真中随意操作机器人，尝试各种控制！

<Aside type="caution" title="Warning（警告）">
    阶段 1 的代码只能在 Systemcore 上运行。
    请注意，这些代码只在仿真中测试过，尚未在真实的 Kitbot 上测试。
    代码可能无法按预期运行。
</Aside>

<Aside type="caution" title="检查你的 VS Code！">
    阶段 1 使用 **2027 WPILib VS Code**。
    如果还没有安装 **2027 WPILib VS Code**，请按照[开发必备工具](/learning-course/getting-started/required-tools)中的说明操作。

    在 macOS 上，VS Code 的图标没有改成 WPILib 图标，名称仍然显示为 Visual Studio Code。
    [VS Code 概述](/learning-course/getting-started/vscode-overview/)中也提到了这一点。
    因此，开始之前，请确认你使用的是 **2027 WPILib VS Code**。

</Aside>
