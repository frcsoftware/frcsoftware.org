恭喜你完成阶段 0！
能够动手编写代码，是实现机器人各项动作的基础。
完成本阶段学习后，你已经掌握了后续编写机器人程序所需要的 Java 基础能力。
如果你想要复习自己写过的练习，阶段 0 全部练习的答案在 [Stage 0 Solution 仓库](https://github.com/frcsoftware/Stage0-Solution)中。

在阶段 0 中，你已经学习了：

- Java 基础语法，以及如何找到并修复错误
- 进行数学运算和比较数值
- 用条件语句和循环控制代码执行逻辑
- 类、对象和接口，以及把代码拆分到不同文件
- 用数组和列表存储大量数据
