### 快速回顾

还记得吗？`Trigger` 是触发机器人行为的刺激，而这些行为我们称为 `Command`。
我们说 `Trigger` 会“调度” `Command`。

### 如何定义触发器

触发器本质上是返回 boolean 的方法：true 表示激活，false 表示未激活。
可以用 `getAsBoolean()` 方法获取触发器的激活状态：

```java #motorTooFastTrigger

```

触发器可以通过两种方式调度命令：

1. `trigger.onTrue(Command)`：当触发器从未激活变为激活时，调度一个命令。
   在下面的示例中，选择并启用手动操控模式后，`runAtThrottle` 命令就会运行。

```java #teleopEnabledRobot

```

2. `trigger.whileTrue(Command)`：与 onTrue 相同，但当触发器再次变为未激活时，会取消正在运行的命令。
   如果把 `teleopEnabledTrigger.onTrue(...)` 改为 `teleopEnabledTrigger.whileTrue(...)`，那么在 Driver Station（操控站）上停用手动操控模式时，正在运行的 `runAtThrottle` 命令会被中途取消。
