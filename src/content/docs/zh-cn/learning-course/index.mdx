欢迎参加 FRCSoftware 学习课程！
本课程旨在帮助不同技能水平的学生学习如何为 FRC 机器人编程。
课程从学习编写 Java 开始，逐步进阶到为复杂度不断提高的机器人编程。
我们会先以 FRC Kitbot 为例学习机器人的单个机构，再学习更复杂的机器人。

FRC 软件一直在不断变化！
如果你有反馈或建议，欢迎通过 [GitHub](https://github.com/frcsoftware/frcsoftware.org)
或 [Discord](https://discord.com/invite/uUugPrPZFs) 与我们交流。

<Aside type="tip" title="Tip（提示）">
    强烈建议按顺序学习本课程。各个阶段经过精心设计，以循序渐进的方式培养技能。跳过某些阶段会使后续学习变得困难。
</Aside>
