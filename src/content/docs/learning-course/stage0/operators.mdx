In the [Java Fundamentals lesson](/learning-course/stage0/java-fundamentals/), we stored values in variables.
In this lesson, we're going to learn about **operators**, symbols like `+` and `>` that calculate new values from existing ones.
Robot code is full of them.
Counting the balls in the hopper takes `+`, and checking whether the shooter is up to speed takes `>`.

We'll cover four kinds of operators:

- **Arithmetic operators**, which do math
- **Assignment operators**, which update a variable's value
- **Comparison operators**, which compare two values
- **Logical operators**, which combine `true` and `false` values

    voltages all need their decimal parts.

    On `String`s, `==` checks whether two variables refer to the same object,

### `=` vs. `==`

To check whether two values are equal, use a double equals sign, `==`.
A single equals sign, `=`, is the assignment operator.
It sets a variable's value and doesn't compare anything.

Mixing them up is a common mistake.
This line doesn't compile.
Java reads it as an attempt to change the number 6 into 8, which not even Java can do.
The error says that the left-hand side of an assignment must be a variable:

{/* rli:ignore */}

```java
System.out.println(6 = 8);
```

With `==`, Java compares the two values instead, and this prints `false`, since 6 is not equal to 8:

{/* rli:ignore */}

```java
System.out.println(6 == 8);
```

## Logical Operators

**Logical operators** combine `boolean` values, so you can make decisions based on more than one condition at a time,
like "the robot has a ball _and_ is lined up with the target."

<Aside type="note">
    Logical operators have an order of operations, just like arithmetic ones.
    `!` comes first, then `&&`, then `||`. Parentheses change the order, the
    same way they do in math.
</Aside>

## Changing a Variable vs. Using Its Value

An operator on its own calculates a new value, but it doesn't change any variables.
A variable only changes when you assign the result back to it with `=` or another assignment operator.
