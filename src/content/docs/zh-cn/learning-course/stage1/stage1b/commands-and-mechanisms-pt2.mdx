### Default Commands（默认命令）

大多数机构都会定义一个“默认命令”，当没有其他占用该机构的命令处于活动状态时，就运行它。
例如，拾取机构或发射机构的默认命令，就是把所有电机的输出比例永远设为 0。

<Aside type="note" title="Note（备注）">
    对人来说，这就像大脑在手臂不用的时候，让它们自然垂在肩膀下面。
</Aside>

要设置机构的默认命令，只需调用 `setDefaultCommand(Command)`，它是所有机构都有的实例方法：

#### 并行运行命令

`coroutine.awaitAll(a, b, c)` 会并行运行命令 a、b 和 c，等这 3 个命令全部完成后再继续。

```java #parallelCommands

```

另一方面，`coroutine.awaitAny(a, b, c)` 会并行运行 a、b 和 c，直到其中任意一个完成。
然后，它会取消其余的命令。
