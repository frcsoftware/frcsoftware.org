在[前面的课程](/learning-course/stage0/java-fundamentals/)中，我们讨论了 Java 的不同数据类型，
例如 `int`、`double` 和 `String`。
本节课我们将学习**类**。类可以用来创建我们自己的数据类型，以及如何用类创建**对象**。
我们还会定义类的两个组成部分：fields（字段）和 constructors（构造函数）。

## 什么是对象

在开始编写代码之前，需要先弄清楚对象是什么。
到目前为止，我们编写的代码都是从运行程序的计算机这一方来描述的。
例如，`System.out.println("hello");` 读起来像一条指令：“让计算机输出 hello。”

类让我们从另一个角度编写代码，这种方式有时称为 <strong>object-oriented programming（面向对象编程）</strong>。
程序不再由一个执行者完成所有事情，而是由许多对象组成。每个对象都有自己的**状态**和**行为**，
类似于戏剧中的角色。
角色有服装、名字等属性，也有唱歌、说台词等能力。
在代码中，对象的属性保存在**字段**中，对象的能力由**方法**定义。

角色的有些属性在整场戏剧中保持不变，例如名字；
另一些则会随场景变化，例如服装，或者他们站在舞台上的位置。
字段也是如此：有些设定一次后就不再改变，我们称之为 <strong>immutable（不可变）</strong>；
另一些则会随时间变化，我们称之为 <strong>mutable（可变）</strong>。
字段应该可变还是不可变，是设计类时需要做出的选择。
在本节课和下一课中，我们都会看到这两类例子。

在 FRC 代码中，对象通常比戏剧角色更抽象。
`Point` 表示一个位置，`Motor` 表示一台实体电机，等等。
对象也可以只是把相关数据和行为组织在一起的一种方式，
所以它并不一定对应现实中的某个物体。

## 类型的种类

Java 有两类类型：<strong>primitive types（基本类型）</strong>和 <strong>reference types（引用类型）</strong>：

- **基本类型**是语言内置的最基础类型，例如 `int`、`double` 和 `boolean`。
- **引用类型**（也称为对象类型）是由程序员定义的更复杂类型。
  许多引用类型内置在 Java Development Kit（Java 开发工具包，JDK）中，例如 `String`。
  另一些来自外部库，但你也可以定义自己的对象类型。

类是定义对象类型的一种方式。
**类**是创建对象的模板，
用字段和方法定义对象的状态和行为。
**对象**是类的实例。
例如，`"a"` 和 `"b"` 都是 `String` 类的对象。

<Aside title="字面量">
    基本类型是直接存储在内存中的**字面量**。
    例如，`123` 是 `int` 类型的字面量。

    `String` 类型比较特殊，因为它是**引用类型**，
    但可以用字面量创建，例如 `"Hello, world!"`。
    `"Hello, world!"` 是 `String` 类型的引用值。
    因此可以调用它的方法，例如 `length()`。
    `"Hello, world!".length()` 会返回 `13`。

</Aside>

## 定义自己的类

现在我们已经知道类是什么，接下来定义自己的类。
第一个示例是一个简单的 `Point` 类，表示二维空间中的一个点。
它可以帮助我们编写代码，让机器人知道自己在场地上的位置。

在 Java 中，每个类都定义在一个 `.java` 文件中，并以 `public class` 关键字开头。
`public` 关键字表示这个类可以在程序的任何地方访问，包括其他文件。
在本节课后面，我们会再次看到 `public`。那时它用于字段和构造函数，而不是整个类。
`class` 关键字告诉 Java 我们正在定义一个新类，后面跟着我们给它的名称 `Point`。

创建一个名为 `Point.java` 的新文件，并这样开始：

{/* rli:ignore */}

```java
public class Point {

}
```

接下来添加三个字段。
**字段**是属于类的变量，用于保存对象状态的一部分。
每个 `Point` 对象都有自己的一份字段副本，因此两个不同的 `Point` 对象可以有不同的坐标。
首先添加两个 `double` 字段 `x` 和 `y`，表示点的坐标。
每个 `Point` 对象的 `x` 和 `y` 都可以不同。

```java {point}#finalFields

```

注意，我们使用 `final` 关键字使这些字段**不可变**。
这意味着它们一旦创建，值就不能再改变。
通常情况下，除非有明确的理由，否则应该把所有字段都设为 `final`。
在下一课中，我们会看到这样的理由。
我们还使用 `private` 关键字使这些字段成为**私有**字段。
这意味着只有同一个类中的方法才能访问它们。

到目前为止，`x` 和 `y` 字段都属于某一个具体的 `Point` 对象。
不过，有时我们想要一个由该类的所有对象共享的值，而不是每个对象各有一份。
接下来添加一个静态常量字段 `ORIGIN`，表示原点 (0, 0)。

```java {point}#staticConstant

```

`static` 关键字用于创建**静态**字段。
静态字段由类的所有实例共享。
在这里，`ORIGIN` 字段由所有 `Point` 对象共享，表示原点 (0, 0)。
静态字段和方法通过类名访问，而不是通过类的实例访问，
因此 `ORIGIN` 字段通过 `Point.ORIGIN` 访问。
`ORIGIN` 字段也是 `public` 的，所以程序的任何地方都可以访问它。
因为它既是 `static` 又是 `final`，所以 `ORIGIN` 是一个 <strong>constant（常量）</strong>。
这也是它的名字使用大写下划线命名法的原因，[Java基础](/learning-course/stage0/java-fundamentals/#名称)中介绍过这种写法。

<Aside type="tip" title="静态与实例">
    非静态字段和方法分别称为**实例字段**和**实例方法**，以便与静态字段和方法区分。
</Aside>

## Constructors（构造函数）

目前还没有任何代码给 `x` 和 `y` 赋上值。
这是**构造函数**要完成的工作：使用 `new` 关键字创建对象时执行的一段特殊代码。
它通常用来给对象的字段设置初始值。

构造函数是一种**方法**。方法是属于类的、有名字的代码块，用来定义类行为的一部分。
我们将在[下一课](/learning-course/stage0/classes-methods/)中自己编写方法。
目前只需要构造函数，以及用来读取字段值的简单方法。

定义构造函数时，先写 `public` 关键字，
然后写类名，再在圆括号中写参数列表。
**参数**是调用构造函数时传入的值。

```java {point}#constructor

```

这样就可以用 `new` 关键字创建新的 `Point` 对象。
例如，点 (1, 1) 可以用 `new Point(1, 1)` 创建。
`new Point (1, 1)` 是 `Point` 类的一个对象。

这里需要注意 `this` 关键字。
`this` 用来表示当前对象。
它用于访问对象的字段和方法。
在这个示例中，我们用 `this` 访问当前对象的 `x` 和 `y` 字段，
并把它们设为参数 `x` 和 `y` 的值。
这里必须使用 `this`，因为参数名和字段名相同。
所以 `this.x` 指字段 `x`，而 `x` 指参数 `x`。
`this` 并不总是必需的：如果方法参数的名称与它们要设置的字段不同，
Java 已经能够区分它们，就可以省略 `this`。

## Getter（获取器）

接下来我们要定义一些 getter 方法。getter 方法的作用很简单：获取并返回一个成员变量（field）的值。它的返回值类型和对应的成员变量一致，并且不带参数。
由于 `x` 和 `y` 这两个成员变量是私有（private）的，我们必须编写 getter 方法，才能让其他类访问到它们：

```java {point}#getters

```

getter 方法是最简单的一种方法。
方法名前面的 `double` 是它的**返回类型**，也就是方法返回给调用者的值的类型。
`return` 关键字负责把这个值返回回去。
可以看到，getter 方法按照惯例以 `get` 开头，后面跟着成员变量（field）的名称。

## 创建和使用对象

有了构造函数和 getter 方法之后，`Point` 就是一个可以实际使用的类型：

```java {usage}#createPoint

```

我们使用 `new` 关键字和构造函数创建新的 `Point` 对象。
这会执行刚才编写的构造函数，并返回一个新的对象。
然后使用点运算符（`.`）调用对象的方法：
`a.getX()` 的意思是“在对象 `a` 上调用 `getX` 方法”。
在这次调用中，`a` 就是 `this` 所指的对象。
任何方法调用都使用同样的形式：`object.method(arguments)`。
