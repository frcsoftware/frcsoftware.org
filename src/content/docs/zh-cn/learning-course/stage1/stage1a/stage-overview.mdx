欢迎来到阶段 1A！
本阶段将运用你的 Java 知识，编写控制机器人的代码。
你可能会问：是什么机器人？
答案是 2026 年 FIRST Robotics Competition 的 Kitbot，它是新 FRC 队伍最好的起点，也是最容易完全运行起来的机器人。
可以观看下面的视频，进一步了解 Kitbot 具备哪些功能。

<YouTube url="https://www.youtube.com/watch?v=nTmZXOgHntM" />

## 阶段 1A 目标

完成阶段 1A 后，你将写出自己的第一份机器人代码，并在仿真中看到 Kitbot 行驶。
你的代码将控制机器人的行驶和得分机构，并运行一个自动程序。

<Aside type="caution" title="Warning（警告）">
    阶段 1A 的代码只能在 Systemcore 上运行。
    请注意，这些代码只在仿真中测试过，尚未在真实的 Kitbot 上测试。
    代码可能无法按预期运行。
</Aside>

<Aside type="caution" title="检查你的 VS Code！">
    阶段 1A 使用 **2027 WPILib VS Code**。
    如果还没有安装 **2027 WPILib VS Code**，请按照[开发必备工具](/learning-course/getting-started/required-tools)中的说明操作。

    在 macOS 上，VS Code 的图标没有改成 WPILib 图标，名称仍然显示为 Visual Studio Code。
    [VS Code 概述](/learning-course/getting-started/vscode-overview/)中也提到了这一点。
    因此，开始之前，请确认你使用的是 **2027 WPILib VS Code**。

</Aside>
