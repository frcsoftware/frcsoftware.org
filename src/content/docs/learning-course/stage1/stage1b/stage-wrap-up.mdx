Congratulations on completing Stage 1B!
The skills you've learned with command-based programming will be useful to you throughout your entire journey as a FRC programmer.
These serve as the basis for a wide range of complex functionality and automation that will enable your robots to be highly effective and automated machines.

Having completed Stage 1B, you're able to:

- Create Mechanisms and Commands
- Bind Commands to Triggers
- Compose commands to create more complex constructions
- Utilize Commands to create auto routines
