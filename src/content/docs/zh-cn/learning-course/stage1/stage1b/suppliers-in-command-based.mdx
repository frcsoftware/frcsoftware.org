### 为什么？

回想一下，`Robot` 类的构造函数是在机器人代码首次加载时调用的，而不是在机器人启用时调用的。
这时，你的手甚至还没有放到控制器上，所以 `controllerOutput` 的值是 0。

机器人启用后，`getLeftY()` 的值会变化；但是，传给 `runAtThrottle` 命令的 `throttle` 参数的值不会变化，因为它的值在命令开始之前就已经确定了。

实际上，我们也是用这种语法来定义 `Trigger` 的：

```java #triggerBooleanSupplier

```

不过要注意，`() ->` 后面的表达式是 `boolean`，而不是 `double`。

<Aside type="note" title="Note（备注）">
    要获取 `BooleanSupplier` 的最新值，需要改为调用 `getAsBoolean()`。
</Aside>
