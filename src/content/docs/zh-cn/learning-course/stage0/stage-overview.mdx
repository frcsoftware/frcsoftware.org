学习 Java 是学习 FRC 编程最重要的一步。
使用 Java，可以编写代码来运行电机、调节电机的速度，以及完成更多操作。
关于 Java 要学的内容很多，但阶段 0 只涵盖编写机器人代码所需的基础知识。

阶段 0 的每一课都会介绍一个不同的核心主题，并且会在前面课程的基础上继续展开。
如果你是编程新手，请**按顺序学习这些课程**。

本阶段涵盖以下主题：

- [Java基础](/learning-course/stage0/java-fundamentals/)
- [Debugging（调试）](/learning-course/stage0/debugging/)
- [Operators（运算符）](/learning-course/stage0/operators/)
- [Conditionals（条件语句）](/learning-course/stage0/conditionals/)
- [Loops（循环）](/learning-course/stage0/loops/)
- [Classes and Objects（类与对象）](/learning-course/stage0/classes-objects/)
- [Methods and Mutable State（方法与可变状态）](/learning-course/stage0/classes-methods/)
- [Arrays and For-Each Loops（数组与 for-each 循环）](/learning-course/stage0/arrays/)
- [Interfaces, Generics, and Lists（接口、泛型与列表）](/learning-course/stage0/interfaces-lists/)
