Learning Java is the most important step in learning FRC programming.
Using Java, we can write code that allows a robot to run a motor, adjust its speed, and much more.
There's a lot to learn about Java, but Stage 0 only covers the basics you'll need for robot code.

Each lesson in Stage 0 covers a different essential topic, and builds on the lessons before it.
If you're new to programming, **go through the lessons in order**.

This stage covers the following topics:

- [Java Fundamentals](/learning-course/stage0/java-fundamentals/)
- [Debugging](/learning-course/stage0/debugging/)
- [Operators](/learning-course/stage0/operators/)
- [Conditionals](/learning-course/stage0/conditionals/)
- [Loops](/learning-course/stage0/loops/)
- [Classes and Objects](/learning-course/stage0/classes-objects/)
- [Methods and Mutable State](/learning-course/stage0/classes-methods/)
- [Arrays and For-Each Loops](/learning-course/stage0/arrays/)
- [Interfaces, Generics, and Lists](/learning-course/stage0/interfaces-lists/)
