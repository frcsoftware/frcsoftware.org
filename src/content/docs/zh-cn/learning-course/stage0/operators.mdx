在 [Java基础](/learning-course/stage0/java-fundamentals/) 这一课中，我们把值存在变量里。
这一课学习 **运算符**，也就是像 `+` 和 `>` 这样的符号，用来根据已有的值计算出新的值。
机器人代码里到处都是运算符。
数储球仓里的球要用 `+`，检查射球机构是否达到速度要用 `>`。

我们会介绍四种运算符：

- <strong>Arithmetic operators（算术运算符）</strong>，用来做数学运算
- <strong>Assignment operators（赋值运算符）</strong>，用来更新变量的值
- <strong>Comparison operators（比较运算符）</strong>，用来比较两个值
- <strong>Logical operators（逻辑运算符）</strong>，用来组合 `true` 和 `false`

<Aside type="caution" title="Dividing Integers（整数相除）">
    一个 `int` 除以另一个 `int` 时，结果也是 `int`，小数部分会被丢掉，所以 `7 / 2` 是 `3`，不是 `3.5`。
    要得到带小数的结果，其中至少一个数必须是 `double`。`7.0 / 2` 是 `3.5`。

    这也是机器人代码大多使用 `double` 的原因之一。速度、位置和电压都需要保留小数部分。

</Aside>

### `=` 与 `==`

要检查两个值是否相等，使用双等号 `==`。
单个等号 `=` 是赋值运算符。
它设置变量的值，不做比较。

把它们弄混是常见错误。
下面这行代码无法通过编译。
Java 会把它理解成试图把数字 6 改成 8，这在java中是做不到的。
错误信息会说，赋值的左边必须是一个变量：

{/* rli:ignore */}

```java
System.out.println(6 = 8);
```

换成 `==` 后，Java 比较的是两个值，并且会打印 `false`，因为 6 不等于 8：

{/* rli:ignore */}

```java
System.out.println(6 == 8);
```

## Logical Operators（逻辑运算符）

**逻辑运算符**用来组合 `boolean` 值，这样可以同时根据多个条件做判断，例如“机器人有球，并且已经对准目标”。

<Aside type="note" title="Note（备注）">
    逻辑运算符也有运算顺序，和算术运算符一样。 `!` 最先，然后是 `&&`，最后是
    `||`。括号可以改变顺序，和数学里一样。
</Aside>

## 改变变量与使用它的值
