Congratulations on completing Stage 0!
Being able to write the actual code is the foundation of making a robot do anything.
By completing Stage 0, you've learned the Java that will power anything you could need your robot to do in the future.
If you want to review your work, the answers to the Stage 0 exercises are in the [Stage 0 Solution repository](https://github.com/frcsoftware/Stage0-Solution).

In Stage 0, you've learned about:

- Basic Java syntax, and how to find and fix errors
- Doing math and comparing values
- Controlling which code runs using conditionals and loops
- Classes, objects, and interfaces, and splitting your code into different files
- Storing many values together in arrays and lists
