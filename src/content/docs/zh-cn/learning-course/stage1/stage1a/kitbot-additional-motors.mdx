# 剩余的电机

Kitbot 还有两个电机，让它可以拾取和发射 fuel（燃料球）。

IntakeLauncher 电机同时驱动拾取机构的滚轮和发射器的飞轮。

<ContentFigure
    width="650px"
    alt="Kitbot 上的拾取-发射子系统"
    src="/learning-course/stage1/stage1a/intakeLauncher.webp"
/>

Feeder 电机根据转动方向，把燃料球送入料斗、送入发射器，或者从拾取机构送出。

<ContentFigure
    width="650px"
    alt="Kitbot 上的送料子系统"
    src="/learning-course/stage1/stage1a/feederMotor.webp"
/>

IntakeLauncher 电机位于 CAN 总线 `CAN_S0`，CAN ID 为 4；Feeder 电机位于 CAN 总线 `CAN_S0`，CAN ID 为 5。

在 `Robot.java` 文件中，为 IntakeLauncher 和 Feeder 电机创建电机控制器实例。

# 燃料球仿真

如果此时仿真代码，就可以用键盘输入控制电机，并在 AdvantageScope 中用图表查看电机的转速。
这个方案虽然可用，但利用 AdvantageScope 的 3D 标签页可以让它更有趣。
AdvantageScope 的 3D 标签页会根据机器人代码发布的数据，在比赛场地中显示机器人和赛件。
`FuelSim` 类提供燃料球赛件的仿真数据，用来直观显示燃料球进入和离开机器人的过程。
创建 `SingleFlywheelSim` 实例时，IntakeLauncher 和 Feeder 电机的引用会被传给 `FuelSim` 类。

要让 `FuelSim` 类工作，需要在 `simulationPeriodic()` 中调用它的 `periodic()` 函数。

        ```

    </TabItem>
    <TabItem label="REV">

        ```

    </TabItem>

</Tabs>

# 在手动操控模式中控制额外的电机

要控制新的电机，需要在 `MyTeleop` OpMode 的 `periodic()` 函数中向这些电机发出指令。
按下控制器的右肩键时，`IntakeLauncher` 电机的 throttle（输出比例）应为 0.9，`Feeder` 电机的输出比例应为 0.75。
这样就会发射燃料球。

<Tabs syncKey={REV_CTRE_CHOOSER_KEY}>
    <TabItem label="CTRE">

        ```java {ctreTeleop}#launchFuel
        ```

    </TabItem>
    <TabItem label="REV">

        ```java {revTeleop}#launchFuel
        ```

    </TabItem>

</Tabs>

按下控制器的左肩键时，IntakeLauncher 电机的输出比例应为 0.8，Feeder 电机的输出比例应为 -1.0。
这样就会拾取燃料球。

<Tabs syncKey={REV_CTRE_CHOOSER_KEY}>
    <TabItem label="CTRE">

        ```java {ctreTeleop}#intakeFuel
        ```

    </TabItem>
    <TabItem label="REV">

        ```java {revTeleop}#intakeFuel
        ```

    </TabItem>

</Tabs>

按下控制器的 A 键时，IntakeLauncher 电机的输出比例应为 -0.8，Feeder 电机的输出比例应为 1.0。
这样就会排出燃料球。

<Tabs syncKey={REV_CTRE_CHOOSER_KEY}>
    <TabItem label="CTRE">

        ```java {ctreTeleop}#outakeFuel
        ```

    </TabItem>
    <TabItem label="REV">

        ```java {revTeleop}#outakeFuel
        ```

    </TabItem>

</Tabs>

当以上按键都没有按下时，IntakeLauncher 和 Feeder 电机的输出比例都应为 0.0。
这样就会让电机停止。

<Tabs syncKey={REV_CTRE_CHOOSER_KEY}>
    <TabItem label="CTRE">

        ```java {ctreTeleop}#stopMotors
        ```

    </TabItem>
    <TabItem label="REV">

        ```java {revTeleop}#stopMotors
        ```

    </TabItem>

</Tabs>

# Line Graph（折线图）

在手动操控模式中测试新电机的过程，与测试底盘驱动系统的过程非常相似。
按住“E”键会让机器人拾取，按住“Q”键会让机器人发射，按住“R”键会让机器人排出。
这次不看 AdvantageScope 中的 2D Field（2D 场地）标签页，而是使用 Line Graph 标签页查看电机数据。
电机控制器施加给电机的电压显示在左侧坐标轴上，右侧坐标轴则显示电机的速度。
