要为 FRC 机器人编程并跟随本网站学习，需要安装 WPILib 工具和 Git，并注册 GitHub 账户。

## WPILib 工具

首先需要安装 WPILib 工具包。
WPILib 工具包包含特定版本的 VS Code，队伍可以使用它编写代码，并将代码 deploy（部署）到机器人。

本网站要求使用 2027 赛季 WPILib 的 alpha 版本。
下载链接请参阅[此处](https://github.com/wpilibsuite/allwpilib/releases)。

<Aside type="note" title="Note（备注）">
    WPILib 工具的安装说明以 2026 版本为例。 2027 与 2026
    版本的安装过程相同，因此可以按照该说明操作。 请确保安装的是 2027 WPILib
    工具，而不是 2026 WPILib 工具。
</Aside>

下载 2027 WPILib 工具后，可以按照[此处](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html)的说明完成安装。

WPILib 工具包还包含适用于 data logging（数据日志记录）、Simulation（仿真）、仪表盘等用途的程序。
后续阶段将使用其中的一部分工具。

### Driver Station（操控站）

如果需要控制实体机器人，可能还需要安装 FRC Game Tools（FRC 比赛工具包）。
该工具包会安装 Driver Station，这是一款连接并控制机器人的程序。
安装说明请参阅[此处](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/frc-game-tools.html)，但完成本课程并不要求安装它。

## Git

接下来需要安装 Git。
Git 是 FRC 中常用的版本控制系统，可以帮助队伍在机器人制作和比赛赛季期间跟踪代码变更。
队伍还可以使用 GitHub 提供的 Pull Requests（合并请求）、Issues（议题）和项目看板等功能管理机器人代码。
Git 的安装说明请参阅[此处](https://git-scm.com/install/)。

## 创建 GitHub 账户

GitHub 是托管 Git repositories（仓库）并支持代码协作的网站。
GitHub 不仅免费且易于使用，还是行业标准，因此在 FRC 中得到广泛应用。

本网站的许多课程都需要使用 GitHub 账户。
可以在[此处](https://github.com/signup)注册账户。
还建议申请 [GitHub Student Developer Pack（GitHub 学生开发者包）](https://education.github.com/pack)，以获取各种资源。
