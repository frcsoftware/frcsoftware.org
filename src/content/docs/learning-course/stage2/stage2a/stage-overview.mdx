Welcome to Stage 2A!
This stage will begin the development of the code for Midtide, team 4322's 2025 offseason robot.
Stage 2A covers feedforward control, where you'll develop the code for the elevator, arm, and claw.
Stage 2A will also introduce the concept of a superstructure, which allows the arm and elevator to be controlled together and coordinate with each other.

In case you're not familiar with the 2025 FRC game, you can watch the game animation.

<YouTube url="https://www.youtube.com/watch?v=YWbxcjlY9JY" />

Midtide is team 4322's 2025 offseason robot.
While the real Midtide can manipulate both the coral and algae game pieces, for the sake of simplicity, the course will only involve the coral side of the robot.
Midtide has an intake that can acquire coral from the ground in any orientation and pull it into an indexer.
From the indexer, the claw mounted to the arm and elevator can then grab the coral and deliver it to any branch on the reef.
