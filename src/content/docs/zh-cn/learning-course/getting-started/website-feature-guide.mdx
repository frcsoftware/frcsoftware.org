在开始学习之前，需要先了解网站中的一些功能，否则可能难以高效地完成课程。
下面通过示例介绍这些功能，帮助你在浏览网站前快速掌握它们。

## 全站功能

- [链接](/learning-course/)以紫色文字显示。
- 点击图片可将其放大，并在适用时显示说明文字。
  按 `Esc` 键可再次缩小图片。
- 网站提供与课程内容相关的[术语表](/resources/glossary/)。
  术语表中的词语在网站中出现时会带有下划线。
  将鼠标悬停在这些带下划线的词语上，即可快速查看定义（例如 PDH、SPARK MAX）。
- 部分信息隐藏在下拉框中。
  请尽量查看其中的大部分内容！

<Aside type="hint" title="Hint（提示）">
    问题的提示隐藏在这样的 Hint（提示）下拉框中。
</Aside>

<Aside type="answer" title="Answer（答案）">
    问题的答案隐藏在这样的 Answer（答案）下拉框中。
</Aside>

FRCSoftware 主要介绍针对不同电机编写代码的两种方式。
在后续阶段中，将使用标签页来区分这些差异。
要查看基于 REV 电机的代码，请点击 REV 标签页。
要查看基于 CTRE 电机的代码，请点击 CTRE 标签页。
