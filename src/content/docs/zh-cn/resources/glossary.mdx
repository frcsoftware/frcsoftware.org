## 常用术语中英对照

下面的表格列出课程中常用、但没有收录在上方术语表中的术语，方便你对照英文资料和代码。

### 命令框架

| 英文                      | 中文           | 说明                                                    |
| :------------------------ | :------------- | :------------------------------------------------------ |
| Command-Based Programming | 基于命令的编程 | 把机器人行为建模为由触发器调度的命令                    |
| Command                   | 命令           | 机器人要执行的一个动作                                  |
| command body              | 命令体         | 定义命令运行后要执行哪些动作的代码                      |
| Trigger                   | 触发器         | 决定命令何时运行的条件或事件                            |
| Mechanism                 | 机构           | 可以通过命令更新状态的机器人组成部分                    |
| requirements              | 资源占用要求   | 命令声明自己要占用的机构                                |
| Scheduler                 | 命令调度器     | 运行所有处于活动状态的命令，并处理机构的占用            |
| default command           | 默认命令       | 没有其他命令占用某个机构时，该机构运行的命令            |
| priority                  | 优先级         | 两个命令占用同一个机构时，决定保留哪一个                |
| coroutine                 | 协程           | 命令体中用来等待、让出执行或运行其他命令的对象          |
| modifier                  | 修饰方法       | 为命令附加超时、停止条件等的方法，例如 `withTimeout()`  |
| Supplier                  | 供给器         | 每次调用时重新计算并返回值的对象，例如 `DoubleSupplier` |
| Lambda Expression         | Lambda 表达式  | 形如 `() -> expression` 的写法                          |
| Commands v3               | 命令框架v3     | 本课程使用的 WPILib 命令框架版本                        |

### 运行模式与仿真

| 英文               | 中文            | 说明                                           |
| :----------------- | :-------------- | :--------------------------------------------- |
| OpMode             | 运行模式程序    | 向操控站注册名称和机器人模式的类               |
| Driver Station     | 操控站          | 用来选择模式、启用机器人和连接控制器的软件     |
| Autonomous         | 自动模式        | 比赛开始时机器人自主运行的阶段                 |
| autonomous routine | 自动程序        | 在自动模式下运行的一套动作                     |
| Teleop             | 手动操控模式    | 由驾驶员用控制器操控机器人的阶段               |
| enabled / disabled | 已启用 / 未启用 | 机器人是否允许驱动电机等执行器                 |
| Periodic Method    | 周期执行方法    | 默认每 20 ms 调用一次的方法                    |
| Simulation         | 仿真            | 在电脑上运行机器人代码，并模拟实体机器人的响应 |
| Sim GUI            | 仿真图形界面    | 仿真时代替操控站，并显示仿真设备信息的窗口     |
| Telemetry          | 遥测            | 记录并发送机器人实时数据的过程                 |

### 底盘与控制

| 英文              | 中文              | 说明                                                 |
| :---------------- | :---------------- | :--------------------------------------------------- |
| Drivetrain        | 底盘驱动系统      | 让机器人在场地上移动的整套驱动系统                   |
| tank drive        | 坦克式底盘        | 左右两侧分别由各自一侧的电机独立驱动的底盘           |
| Arcade Drive      | 前进转向组合操控  | 摇杆 y 轴控制前进后退，x 轴控制旋转                  |
| Leader / Follower | 主电机 / 跟随电机 | 跟随电机执行发给主电机的指令                         |
| invert            | 反向设置          | 决定收到正值指令时电机朝哪个方向转动                 |
| duty cycle        | 占空比            | 电机以最大输出的某个百分比运行，取值范围 -1.0 到 1.0 |
| throttle          | 输出比例          | 发给电机的输出大小，通常用占空比表示                 |
| PID controller    | PID 控制器        | 根据期望状态与当前状态的差值计算输出的控制器         |
| setpoint          | 设定值            | 控制器要让机构达到的目标状态                         |
| feedforward       | 前馈              | 根据已知的物理模型预先计算输出的控制方式             |
| Heading           | 航向              | 机器人在场地上的朝向                                 |
| Odometry          | 里程计            | 根据编码器和陀螺仪数据推算机器人位置的方法           |
| spinup            | 加速至目标转速    | 先让飞轮等机构加速到目标转速，再执行后续动作         |

### 传感器与机构

| 英文                        | 中文                  | 说明                                   |
| :-------------------------- | :-------------------- | :------------------------------------- |
| Motor Controller            | 电机控制器            | 接收指令并控制电机速度和方向的电子设备 |
| Encoder                     | 编码器                | 测量旋转运动，返回位置和速度           |
| Relative / Absolute Encoder | 相对式 / 绝对式编码器 | 断电后是否保留位置数据                 |
| Beam Break                  | 对射光电传感器        | 检测两点之间的光束是否被物体遮挡       |
| IMU                         | 惯性测量单元          | 结合加速度计和陀螺仪，测量朝向和旋转   |
| Gyroscope                   | 陀螺仪                | 测量旋转速率的传感器                   |
| CAN Bus                     | CAN 总线              | 设备连接的 CAN 通信线路                |
| CAN ID                      | CAN 设备 ID           | 同一条 CAN 总线上每个设备唯一的编号    |
| Intake                      | 拾取机构              | 从场地上收集赛件的机构                 |
| Shooter                     | 发射机构              | 把赛件发射出去的机构                   |
| Launcher                    | 发射器                | 负责发射赛件的部件                     |
| Feeder                      | 送料机构              | 把赛件送入发射器或其他机构             |
| Indexer                     | 整理输送机构          | 在机器人内部移动和排列赛件             |
| Hopper                      | 料斗                  | 暂时存放赛件的容器                     |
| Flywheel                    | 飞轮                  | 高速转动、用来发射赛件的轮子           |
| Game Piece                  | 赛件                  | 比赛中用来得分的物品                   |
